 Day 2 - Scala Collections Practice

Objective

The objective of this project is to practice Scala Collections without using Spark.

 Topics Covered

- List
- map
- filter
- flatMap
- reduce
- Vector
- Map
- for-comprehension
- Daily sales summary

 Scenario

A simple daily sales system is created using Scala collections.

The program:

1. Processes sales records using `map`
2. Filters sales using `filter`
3. Expands products using `flatMap`
4. Calculates total sales using `reduce`
5. Uses Vector for indexed customer records
6. Uses Map to calculate product quantities and revenue
7. Combines customers and orders using a for-comprehension
8. Produces a daily sales summary
 Run

```bash
scalac SalesSummary.scala
